Estás desarrollando un pequeño sistema que simula
el control de dispositivos IoT en una casa inteligente. 
Cada dispositivo (ej. lámpara, termostato, cerradura) 
tiene una estructura con su nombre, estado (encendido/apagado),
y métodos para operar sobre ellos.

Tareas 🧩
● Definir una estructura Dispositivo que tenga al menos:
    ○ Nombre (string). Longitud máxima: 10.
    ○ Estado (bool: true = encendido, false = apagado)
● Crear una interfaz Controlable con métodos:
    Encender() error 
    Apagar() error 
    EstadoActual() string
● Hacer que Dispositivo implemente la interfaz.
● En main(), crear una lista de dispositivos, encenderlos o apagarlos aleatoriamente,
    e imprimir su estado.
● Usar una librería externa (github.com/fatih/color) para imprimir los estados
     en colores distintos según estén encendidos o apagados.
● Si se intenta encender un dispositivo ya encendido, la función debe devolver 
    un error descriptivo. Lo mismo para apagar uno apagado.
 
YAPA: crear un menú en consola que permita:
    ○ Crear un nuevo dispositivo indicando su nombre.
    ○ Elegir uno para prenderlo o apagarlo.
    ○ Visualizar todos los dispositivos indicando si están prendidos o apagados.
